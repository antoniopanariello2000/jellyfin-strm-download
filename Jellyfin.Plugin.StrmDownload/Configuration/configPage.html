Strm Download

Quando abilitato, qualunque richiesta di download nativo (Jellyfin Web, app mobile, ecc.) per un elemento basato su un file .strm scaricherà il contenuto reale puntato dal file invece del piccolo file di testo .strm stesso.

Se disattivata, il download nativo torna al comportamento di default di Jellyfin (scarica il file .strm così com'è).
