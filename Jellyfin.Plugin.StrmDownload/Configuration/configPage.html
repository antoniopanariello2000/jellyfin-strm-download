STRM Download Proxy

Wenn aktiviert, lädt jede native Download-Anfrage (Jellyfin Web, Mobil-Apps usw.) für ein Element auf Basis einer .strm-Datei den tatsächlichen Inhalt herunter, auf den die Datei verweist, statt der kleinen .strm-Textdatei selbst.

Wenn deaktiviert, fällt der native Download auf das Standardverhalten von Jellyfin zurück (lädt die .strm-Datei so herunter, wie sie ist).
Bricht die Übertragung ab, wenn die Gegenstelle so lange keine Daten mehr liefert. Die Zeit wird nach jedem empfangenen Datenblock zurückgesetzt, lange aber gesunde Downloads werden also nicht abgebrochen. 0 deaktiviert die Überwachung.
